Project Title:
Responsive Student Dashboard

Features Implemented:
1. Semantic HTML structure.
2. Header and responsive navigation.
3. Welcome section.
4. Three dashboard cards.
5. Recent activity and announcements.
6. Mobile-first CSS design.
7. CSS Grid and Flexbox layouts.
8. Mobile, tablet and desktop media queries.
9. Responsive progress bar.
10. Accessible labels and visible keyboard focus.
11. Consistent colors, spacing and card shadows.

Viewport Sizes Tested:
1. Mobile: 375px
2. Tablet: 768px
3. Desktop: 1280px

How to Run:
1. Keep index.html, style.css and README.txt in the same folder.
2. Open index.html in a web browser.
3. Resize the browser or use Developer Tools to test
   different screen sizes.
